## 🔑 **How to Get Your FREE Google Gemini API Key:**

### Step 1: Visit Google AI Studio
Go to: [https://makersuite.google.com/app/apikey](https://makersuite.google.com/app/apikey)

### Step 2: Sign In
- Use your Google account to sign in
- Accept the terms of service

### Step 3: Create API Key
- Click "Create API Key"
- Choose "Create API key in new project" (recommended)
- Copy your API key (keep it secure!)

### Step 4: Configure in App
1. Open the AI Chat Assistant
2. Click the Settings (⚙️) button in the top right
3. Paste your API key in the "Google Gemini API Key" field
4. Adjust temperature and token settings as needed
5. Start chatting!

## 💡 **API Key Security:**

## 🎛️ **Settings Explained:**

### **Temperature (0.0 - 1.0):**
- **0.0**: More focused, deterministic responses
- **0.7**: Balanced creativity (recommended)
- **1.0**: Maximum creativity and randomness

### **Max Tokens:**
- Controls response length
- **1024**: Good for most conversations
- **2048**: Longer, more detailed responses

## 🔧 **Troubleshooting:**

### **"Please configure your API key" message:**
- Make sure you've entered your Gemini API key in settings
- Check that the key is valid and active

### **API errors:**
- Verify your API key is correct
- Check your Google AI Studio quota
- Ensure stable internet connection

### **App not responding:**
- Refresh the browser page
